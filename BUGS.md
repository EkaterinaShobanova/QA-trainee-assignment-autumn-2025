# Баг-репорты

## Баг 1: GET запросы к эндпоинтам возвращают 400 вместо данных

*   **Эндпоинты:** 
    - `GET /api/1/item/{id}` 
    - `GET /api/1/statistic/{id}`
*   **Шаги воспроизведения:**
    1. Отправить GET запрос на любой из указанных эндпоинтов
*   **Ожидаемый результат:** Status Code 200 с данными
*   **Фактический результат:** Status Code 400 (Bad Request)
*   **Серьезность:** High
*   **Приоритет:** High
*   **Влияние:** Невозможно получить объявления по ID и статистику

## Баг 2: Создание объявления возвращает 200 но без ID

*   **Эндпоинт:** `POST /api/1/item`
*   **Шаги воспроизведения:**
    1. Отправить POST запрос с валидными данными
*   **Ожидаемый результат:** Status Code 201/200 с полем ID в ответе
*   **Фактический результат:** Status Code 200, но ответ не содержит ID созданного объявления
*   **Серьезность:** Medium  
*   **Приоритет:** Medium
*   **Влияние:** Не ясно, как идентифицировать созданное объявление для дальнейших операций
