# Тест-кейсы для API объявлений

## 1. Создать объявления (POST /api/1/item)

### TC1. Успешное создание объявления
- **Шаги:** 
  - Имеем валидные данные для объявления
  - Отправляем POST запрос на создание объявления
- **Ожидаемый результат:** Получаем статус код 200

### TC2. Создание с невалидным sellerId
- **Шаги:**
  - Имеем данные с невалидным sellerId
  - Отправляем POST запрос на создание объявления
- **Ожидаемый результат:** Получаем статус код 400

## 2. Получить объявления по идентификатору (GET /api/1/item/{id})

### TC3. Получение объявления по ID
- **Шаги:**
  - Имеем ID объявления
  - Отправляем GET запрос на получение объявления
- **Ожидаемый результат:** Получаем статус код 200

## 3. Получить все объявления по идентификатору продавца (GET /api/1/{sellerID}/item)

### TC4. Получение объявлений продавца
- **Шаги:**
  - Имеем ID продавца
  - Отправляем GET запрос на получение объявлений продавца
- **Ожидаемый результат:** Получаем статус код 200

## 4. Получить статистику по айтем id (GET /api/1/statistic/{id})

### TC5. Получение статистики
- **Шаги:**
  - Имеем ID объявления
  - Отправляем GET запрос на получение статистики
- **Ожидаемый результат:** Получаем статус код 200
